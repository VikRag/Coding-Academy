PHP General-Purpose

A server-side scripting language powering a huge portion of the web, including WordPress. Known for rapid database integration and quick web backend development.

Server-Side Interpreted Dynamic Typing
1994 — Rasmus Lerdorf
Java General-Purpose

Object-oriented language built on "write once, run anywhere." The cornerstone of enterprise software and Android development, running on the JVM for platform independence.

Object-Oriented JVM Statically Typed
1995 — James Gosling, Sun Microsystems
C General-Purpose

One of the most influential languages ever created. C provides direct memory access and maps closely to hardware — the foundation that Unix, Linux, and countless systems are built on.

Low-Level Compiled Procedural
1972 — Dennis Ritchie, Bell Labs
SQL Domain-Specific

The universal language of relational databases. Declarative and expressive, SQL lets you query, insert, update, and manage structured data with minimal code across virtually every database platform.

Declarative Database Query ANSI Standard
1974 — IBM Research
HTML Domain-Specific

HyperText Markup Language defines the structure and semantic meaning of web content. Not a programming language — browsers parse it to build the DOM and render every page on the internet.

Markup Declarative DOM Structure
1993 — Tim Berners-Lee
CSS Domain-Specific

Cascading Style Sheets control the visual presentation of HTML documents — layout, typography, color, spacing, animations, and responsive behavior across devices and screen sizes.

Stylesheet Declarative Visual Styling
1996 — Håkon Wium Lie, W3C
JavaScript Web Dev

The only language that runs natively in every web browser. Powers client-side interactivity and, via Node.js, full server-side development — making it the most widely deployed language on earth.

Interpreted Event-Driven Dynamic Typing
1995 — Brendan Eich, Netscape
HTML Web Dev

The structural backbone of every webpage. HTML defines headings, paragraphs, links, images, forms, and semantic landmarks that assistive technology and search engines rely on.

Markup Declarative Browser Native
1993 — Tim Berners-Lee
CSS Web Dev

Works alongside HTML to define the visual layer of websites. Modern CSS includes Grid, Flexbox, custom properties, and keyframe animations — eliminating the need for many JavaScript libraries.

Stylesheet Responsive Design Animations
1996 — W3C
Swift Mobile

Apple's modern replacement for Objective-C, designed for safety, speed, and clarity. The primary language for building iOS, macOS, watchOS, and tvOS applications natively.

Compiled Type-Safe iOS / macOS
2014 — Apple Inc.
Kotlin Mobile

A concise, expressive language that runs on the JVM. Google's preferred language for Android development — fully interoperable with Java while dramatically reducing boilerplate code.

JVM Null Safety Android
2011 — JetBrains
Dart Mobile

Google's language powering the Flutter framework. Dart compiles to native ARM code for mobile and to JavaScript for web — enabling true cross-platform apps from a single codebase.

Cross-Platform Flutter AOT Compiled
2011 — Google
Python Data & AI

The dominant language of data science and AI, backed by an unrivaled ecosystem — NumPy, Pandas, TensorFlow, and PyTorch. Also widely used for web development, scripting, and automation.

Interpreted Dynamic Typing Vast Ecosystem
1991 — Guido van Rossum
R Data & AI

Built specifically for statistical computing and data visualization. The preferred language in academic research and among statisticians, with powerful packages like ggplot2 and dplyr.

Statistical Computing Data Visualization CRAN Ecosystem
1993 — Ihaka & Gentleman, UoA
Julia Data & AI

Designed for high-performance numerical and scientific computing. Julia achieves near-C execution speeds with Python-like syntax — popular in research, finance, and large-scale simulation.

JIT Compiled High Performance Scientific Computing
2012 — MIT CSAIL
C# Game Dev

The primary language of the Unity game engine, one of the most widely used platforms in game development. C# balances performance with strong tooling and developer productivity.

Unity Engine Object-Oriented .NET Runtime
2000 — Microsoft
C++ Game Dev

Powers AAA game engines like Unreal Engine. C++ gives developers maximum control over hardware and memory — the go-to choice for performance-critical game systems and graphics programming.

Compiled Low-Level Control Unreal Engine
1979 — Bjarne Stroustrup, Bell Labs
Lua Game Dev

A lightweight scripting language embedded into game engines and applications worldwide. Popular in modding systems like Roblox and World of Warcraft for its simplicity, small footprint, and fast runtime.

Scripting Embeddable Lightweight
1993 — PUC-Rio, Brazil
