General-Purpose

General-Purpose Languages

Designed to solve a wide range of problems across many domains — from web backends and enterprise systems to scripting and embedded software. The workhorses of the industry.

Domain-Specific

Domain-Specific Languages (DSLs)

Purpose-built for a narrow, well-defined task. DSLs are optimized for expressiveness within their domain — making complex tasks within that niche far simpler than a general-purpose language ever could.

Web Development

Web Development Languages

The trio powering the internet. HTML structures content, CSS controls presentation, and JavaScript adds interactivity — together they form the foundation of every website you visit.

Mobile Development

Mobile Development Languages

Languages tailored for building native and cross-platform mobile apps. Swift dominates iOS, Kotlin powers Android, and Dart via Flutter bridges both platforms from a single codebase.

Data Science & AI

Data Science & AI Languages

The languages behind machine learning, statistical analysis, and scientific computing. Python leads with its vast ecosystem, R excels at statistical visualization, and Julia delivers near-C numerical performance.

Game Development

Game Development Languages

From indie titles to AAA studios, these handle real-time rendering, physics, and game logic. C# is Unity's backbone, C++ powers Unreal Engine, and Lua is the go-to scripting language for modding systems.
