Basics

Core concepts including variables, operators, control flow, loops, arrays, and basic syntax — the foundation of every Java program.

Introduction & Syntax

Every Java program starts inside a class. The special method called main is where your program begins running.

public class Hello {
    public static void main(String[] args) {
        // This line prints text on the screen
        System.out.println("Hi! I am learning Java!");
        System.out.println("This is my first program ☺");
    }
}

Quick explanation: public static void main is like the "start button" of your program. Everything inside the curly braces { } runs when you start the program.

Variables & Operators

Variables are like labeled boxes where you store numbers, text, or true/false values.

public class Variables {
    public static void main(String[] args) {
        int age = 16;                // whole number
        double price = 4.99;         // decimal number
        String name = "Alex";        // text
        boolean isCool = true;       // true or false

        System.out.println("My name is " + name);
        System.out.println("I am " + age + " years old");

        int score = 85;
        score = score + 10;          // add 10 points
        System.out.println("New score = " + score);
    }
}

Easy tip: Use + to join text and numbers. score += 10 is a shorter way to write score = score + 10.

Control Flow & Loops

We use if to make decisions, and loops to repeat things.

public class Decisions {
    public static void main(String[] args) {
        int marks = 78;

        // Decision with if-else
        if (marks >= 90) {
            System.out.println("Grade A - Awesome!");
        } else if (marks >= 70) {
            System.out.println("Grade B - Good job!");
        } else {
            System.out.println("Keep practicing!");
        }

        // Loop - repeat 5 times
        for (int i = 1; i <= 5; i++) {
            System.out.println("High-five #" + i);
        }
    }
}

Simple rule: for is great when you know how many times to repeat. if helps the computer decide what to do.

Strings & Arrays

Strings hold text. Arrays hold many values of the same type (like a list of scores).

public class Lists {
    public static void main(String[] args) {
        String greeting = "Hello";
        System.out.println(greeting.toUpperCase());     // HELLO
        System.out.println(greeting.length());          // 5 letters

        // Array - list of numbers
        int[] scores = {85, 92, 78, 95, 88};

        System.out.println("First score: " + scores[0]);
        System.out.println("Last score: " + scores[4]);

        // Print all scores
        for (int i = 0; i < scores.length; i++) {
            System.out.println("Score " + (i+1) + ": " + scores[i]);
        }
    }
}

Important: Arrays start counting from 0 (first item = [0]). .length tells you how many items are in the list.

Methods

Methods are like mini-programs inside your program. You can use them again and again!

Methods & Parameters

A method is something you can call whenever you need it — like a reusable recipe.

public class Greetings {
    // Method that takes a name
    public static void sayHello(String name) {
        System.out.println("Hey " + name + "! How's it going?");
    }

    // Method that returns a value
    public static int doubleNumber(int num) {
        return num * 2;
    }

    public static void main(String[] args) {
        sayHello("Mia");           // Call the method
        sayHello("Liam");

        int answer = doubleNumber(7);
        System.out.println("Double of 7 is " + answer);
    }
}

Fun fact: void means "doesn't give anything back". If it says int, double, etc., it returns a value with return.

Overloading & Recursion

Overloading = same method name, different inputs.
Recursion = method calls itself (like Russian dolls).

public class FunMethods {
    // Overloading - same name, different parameters
    public static void show(int n) {
        System.out.println("Number: " + n);
    }

    public static void show(String word) {
        System.out.println("Word: " + word);
    }

    // Recursion example (careful - needs stop condition!)
    public static int countDown(int n) {
        if (n <= 0) {
            System.out.println("Blast off!");
            return 1;
        }
        System.out.println(n + "...");
        return countDown(n - 1);
    }

    public static void main(String[] args) {
        show(42);              // uses int version
        show("Java is cool");  // uses String version

        countDown(5);          // 5 4 3 2 1 Blast off!
    }
}

Tip: Recursion is cool but can be dangerous — always add a clear stopping condition (called the "base case").
